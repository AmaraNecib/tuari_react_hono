# Delegation template

## Goal
Name the bounded result and acceptance source.

## Worktree and revision
Give the absolute owned path, base and committed HEAD. Start every command
with `cd` to that path. Verify it exists before assigning the task.

## Required reading
Name the lifecycle/phase skill, workflow, design and matching wisdom lessons.

## Scope and authority
Name writable paths and excluded work. Reviewers write no source. Validators
write ignored evidence only. Workers do not push, open a PR, merge or write
wisdom. No dependencies or children unless explicitly authorized.

## Verification
Pass the parent's explicit mode: `focused-local / CI-final-pending` or
`focused-local / CI-final-enforced`, with the activation evidence reference.
Name affected tests, direct callers, commands, timeouts and unique log paths.
Require exact SHA, native exit codes, counts, duration and before/after source
identity. Full local work needs a named uncertainty or CI coverage gap.
Use `heavy_run` for justified heavy commands.

## Completion
Return exact base/head, changed files, proof and local evidence path, findings,
applied lessons and blockers. Distinguish expected-red, failed, retried and
passed commands. Keep the report concise. End the async task; completion wakes
the parent. Do not poll or invent a verdict.
