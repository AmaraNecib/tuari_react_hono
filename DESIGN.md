# Design System

## Brand Identity

Tuari is a local-first ERP system with a warm, crafted aesthetic that prioritizes density and functionality over decoration.

### Color Palette

**Light Mode:**
- Background: `#fafafa` (warm off-white)
- Surface: `#f5f5f5`
- Border: `#e5e5e5`
- Text Primary: `#1a1a1a`
- Text Secondary: `#525252`
- Accent: `#b4502a` (terracotta)

**Dark Mode:**
- Background: `#171512` (deep warm black)
- Surface: `#1f1c18`
- Border: `#2d2a22`
- Text Primary: `#f0ebe0`
- Text Secondary: `#a39d91`
- Accent: `#d97a4a` (warm orange)

### Typography

- Display: Instrument Serif (italic for headings)
- Body: Inter Tight / IBM Plex Sans Arabic
- Mono: JetBrains Mono

### Components

- Rounded corners: 12px (cards), 8px (buttons), 6px (inputs)
- Border width: 1px
- Shadows: Minimal, subtle
- Animations: Transform + opacity only (no layout properties)

### Layout

- RTL-first design
- Sidebar: Fixed right side (240px expanded, 64px collapsed)
- Content: Fluid with max-width constraints
- Grid: 2-column forms, responsive tables

### Accessibility

- WCAG AA contrast (4.5:1 minimum)
- 44px minimum touch targets
- Keyboard navigation support
- Reduced motion support
