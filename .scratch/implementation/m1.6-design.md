# M1.6 — License Enforcement (APP_DB_KEY Stripping)

## Summary

Add `.env_clear()` to sidecar process spawning and conditionally include
`APP_DB_KEY` based on license feature check.

## Changes

- `apps/desktop/src-tauri/src/lib.rs`:
  - Add `.env_clear()` before setting specific env vars in `spawn_api_process()`
  - Create `LicenseManager` during startup and pass it to `spawn_api_process()`
  - Check `license_manager.has_feature("encrypted_db")` before setting `APP_DB_KEY`

## Testing

- Build: `cargo build`
- The `.env_clear()` ensures the sidecar doesn't inherit parent env vars
- The `APP_DB_KEY` stripping is tested via unit tests in license.rs (has_feature)
