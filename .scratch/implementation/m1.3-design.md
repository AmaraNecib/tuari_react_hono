# M1.3 — LicenseManager Core Logic

## Public API

### Structs

```rust
// apps/desktop/src-tauri/src/license.rs

pub struct LicenseInfo {
    pub license_id: String,
    pub issued_at: DateTime<Utc>,
    pub issued_to: String,
    pub email: String,
    pub edition: String,
    pub features: Vec<String>,
    pub max_users: u32,
    pub valid_from: DateTime<Utc>,
    pub valid_until: Option<DateTime<Utc>>,
    pub license_type: String,
    pub metadata: HashMap<String, serde_json::Value>,
}

pub struct CustomerInfo {
    pub name: String,
    pub email: String,
}

pub enum LicenseStatus {
    Valid,
    Expired,
    NotYetActive,
    Tampered,
    Grace,
    Invalid,
}

pub enum ActivationResult {
    Activated(LicenseInfo),
    Replaced(LicenseInfo, LicenseInfo),  // old replaced by new
}

pub struct GraceResult {
    pub is_grace: bool,
    pub days_remaining: i64,
}
```

### LicenseManager

```rust
pub struct LicenseManager {
    license: Mutex<Option<LicenseInfo>>,
    clock: ClockStatus,           // M1.4 stub — ClockTracker later
    trusted_keys: Vec<VerifyingKey>,
}

impl LicenseManager {
    pub fn initialize(data_dir: &Path) -> Result<Self, RustCoreError>;
    pub fn activate(&self, license_content: &str) -> Result<ActivationResult, RustCoreError>;

    // Public accessors
    pub fn edition(&self) -> &str;
    pub fn has_feature(&self, feature: &str) -> bool;
    pub fn max_users(&self) -> u32;
    pub fn customer(&self) -> Option<CustomerInfo>;
    pub fn expires_at(&self) -> Option<DateTime<Utc>>;
    pub fn status(&self) -> LicenseStatus;
    pub fn days_remaining(&self) -> i64;
    pub fn to_env_map(&self) -> HashMap<String, String>;

    // Internal
    fn verify_signature(&self, payload: &[u8], signature: &[u8]) -> bool;
}
```

## Implementation Risks

- The wire format parsing (base64url + signature split) is shared between
  verify_signature() and activate().
- The ClockTracker is a stub (M1.4) — clock tamper checks are deferred.
- Rust LicensedFeature enum casing (PascalCase) differs from JSON wire format
  (snake_case). has_feature() should use snake_case matching.

## Deviations from Architecture

- ClockTracker is replaced with a ClockStatus stub until M1.4.
- No key rotation certificate loading yet (M1.5).
- Grace period logic is simplified (basic expiry check only).
