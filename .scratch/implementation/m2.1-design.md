# M2.1 — Package Verification

## Public API

```rust
// apps/desktop/src-tauri/src/update.rs

/// Verify an Ed25519 signature over a manifest payload.
pub fn verify_package_signature(public_key: &[u8; 32], manifest: &[u8], signature: &[u8; 64]) -> Result<(), RustCoreError>;

/// Verify that data matches the expected SHA-256 hash.
pub fn verify_package_hash(data: &[u8], expected_hash: &[u8; 32]) -> Result<(), RustCoreError>;

/// Parse an update manifest from JSON bytes.
pub fn parse_update_manifest(manifest_bytes: &[u8]) -> Result<UpdateManifest, RustCoreError>;
```

## Types

pub struct UpdateManifest {
