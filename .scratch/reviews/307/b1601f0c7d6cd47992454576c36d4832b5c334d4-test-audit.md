- **AC3** (full `test:web` green): ✅ verified — 478/478 pass.

## Edge-case gaps (no action needed)

- Adding/removing a flat factory key, or changing a factory's arity, fails **both** the runtime pinned list and the type-probe union — the two pin points are mutually self-correcting.
- Theoretical future mismatch: a factory with an *optional second* param `(userId, opts?)` would be runtime-flat (`Function.length` 1 ⇒ `<= 1` ⇒ included) but type-excluded (`1 | 2 extends 0 | 1` is false). No such factory exists; the pinned tests force an explicit decision on introduction. Flagged in the design doc's risk section.

## Grade

**B+** — the tests are compile-time assertions that directly encode both acceptance criteria and the bug's regression mechanism; the only weaknesses are style-level (floating promise, redundant `not.toEqualTypeOf`) and the untested zero-param parity edge.

## Residual risks

- The negative probe guards the *type* but runs real code at test runtime; a future refactor that executes side effects inside `invalidateWorkspaceDomains` could make this test misbehave. Low.
- `workspaceSnapshot` joins the `WorkspaceDomain` union (it was already in the runtime flat list). No caller passes it; doing so would only invalidate the snapshot key itself. Behavior-neutral, documented.
