- **ports.ts normalizePort** — unit-tested (ports.test.ts): canonical, +3000 / 1e3 non-canonical, out-of-range, non-numeric, empty, undefined → fallback. (P2 regression proof.)

## Edge/empty/failure states
- Bound/negative/NaN ports → fallback (not crash).
- Malformed PLAYWRIGHT_BASE_URL → default loopback URL, start own server.
- External-host override → no local server started (waits for external).
- Analytics fallback without VITE_API_URL now follows API_PORT (was the P1 gap).
