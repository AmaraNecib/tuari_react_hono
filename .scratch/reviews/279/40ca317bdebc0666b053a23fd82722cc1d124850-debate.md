## Defender arguments

- **Default-deny ACL** (allowlist, not denylist): correct security posture; a
  future window is denied by construction until explicitly added.
- **Pure predicate used in production** (`is_api_sidecar_command_line`): the
  kill decision is made by unit-tested Rust code, not an untested PowerShell
  format string — single source of truth, no drift.
- **Stable layout markers** (not the absolute install path): keep the cleanup
  working after an app update relocates the install directory (NSIS versioned
  paths), which a fixed-path match would miss.
- **Gate placement**: first statement of each gated command — no side effect
  or network I/O (e.g. `start_update_download`'s `reqwest` GET, `apply_update`
  file validation, license write) happens before the check.
- **Exact, case-sensitive label matching** matches Tauri's own label semantics;
  pinned by a dedicated unit test.
- **Minimal diff**: one production file; 2 mechanical clippy lints fixed only
  because the local (newer) toolchain enforces them under `-D warnings`; no new
  dependencies, no Cargo.toml/capabilities/config changes; frontend signatures
  unchanged (window is injected server-side).
