## Edge case hunter

**Verified correct:** seam is a pure delegation
(`withTransaction<T>(callback) { return this.raw.transaction(callback)(); }`,
sqlite-company.repository.ts:129-131); new tests pin real better-sqlite3
behavior (rollback → connection reusable; non-Error rethrown by identity).

**Findings raised (all addressed in the branch):**

| # | Finding | Risk | Resolution |
|---|---------|------|------------|
| E1 | Nested `withTransaction` (savepoint) semantics unpinned — inner commit vs outer rollback | 🟠 | Added "nested withTransaction: an inner commit is undone by the outer rollback" |
| E2 | DB-originated error (UNIQUE constraint) rollback path untested | 🟠 | Added "rolls back on a DB-originated error and leaves the connection usable" (duplicate `employee.phone`) |
| E3 | Externally-opened raw transaction behavior — hunter hypothesised loud failure | 🟠 | Empirically disproven: better-sqlite3 JOINS an open transaction via savepoint. Pinned as "joins an externally-opened raw transaction via savepoint" (writes land in the open tx; caller's ROLLBACK undoes them) |
| E4 | Return-value passthrough only implicitly covered | 🟡 | Added "propagates the callback's return value" |
| E5 | No-op transaction commit path untested | 🟡 | Added "commits a no-op transaction and leaves the connection usable" |

Notes: sync single-connection SQLite has no genuine concurrency race —
reentrancy is the only race-like surface. ROLLBACK-itself-failing is not
reproducible in-memory.
