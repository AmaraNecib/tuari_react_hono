## Critic findings

| # | Severity | Finding | Resolution |
| --- | --- | --- | --- |
| C1 | 5/10 Major | The bar — and the only page-size `NativeSelect` — is gated on `items.length > pageSize`. Picking 50 with 34 items unmounts the control and pins the operator at 50 rows/page with no way back. | **Fixed** in `8a67a33d`. Gate is now `items.length > 0`. |
| C2 | 4/10 Major | A created definition is inserted by `ORDER BY name`, so it can land on any page; the operator stays put and sees an unchanged list with only a toast as proof. | **Fixed** in `8a67a33d`. A `pendingCreatedId` effect follows the new row to its page. |
| C3 | 3/10 Minor | `usePaginatedRows` clamps in `useEffect`, so a cross-page shrink paints one empty, control-less frame. | **Filed** (shared hook, pre-existing, not RTL-observable). Parent decision requested. |
| C4 | 2/10 Minor | No `resetPageDeps`. | **Dismissed.** Filtering would happen before `rows` reaches the hook; there is no filter on this page. |
| C5 | 1/10 Minor | Page-size select has no `aria-label`. | **Filed** (shared control, pre-existing). |

## Defender

- Client-side paging: **correct** (9/10). The endpoint is unpaged end to end and the same query result feeds the home-view stock selector; a server page would truncate it without a second endpoint.
- Shared primitives: **correct** (10/10). No fork, no new i18n keys.
- Gating/`resetPageDeps`: (9/10) — **refuted on the gate by C1**. The defender claimed the size selector cannot strand the user; the code path (`TablePaginationControls` owns the select, page gates the whole control) and the failing test prove otherwise.
- Create ordering: the defender called it an inherent UI limit; the parent accepted C2 as a fix because pagination newly makes the created row invisible in the DOM where it previously rendered (all rows were in the DOM before this change).

## Synthesis

No incorrect-rows or lost-rows defect in the page math itself; the two operator-facing defects are C1 (stranded size control) and C2 (created row off-page). Both fixed with tests that fail on the pre-fix production file.
