## New suite — `features/shared/__tests__/load-error-surface.test.tsx`

| # | Test | Covers |
|---|---|---|
| 1 | loading state renders label, no alert/retry | loading branch |
| 2 | error state renders icon+message+retry (default) | error branch, default dialect |
| 3 | retry click calls `onRetry` once | callback contract |
| 4 | children slot renders inside error surface | optional slot |
| 5 | custom props (icon, classes) render without breaking | backward compat / knobs |
| 6 | `isError === false` renders content slot bare | bare content branch |

Edge cases considered:
- Default `isError` (undefined → error) pins the branch-only call-site
  contract (debts/invoice render the surface only from `isError` branches).
- Default icon assertion via `document.querySelector("svg")` — lucide icons
  are `aria-hidden`, deliberately not reachable by role queries.
- Negative assertions guard cross-branch leakage (`queryByRole("alert")` /
  `queryByRole("button")` null in loading and bare-content branches; loading
  label absent in error branch).
- Failure/empty state coverage: the error branch is the empty/failure state
  of the primitive; all six tests exercise it.
