## Defender defenses

D1 one named read shape used at exactly the five storage sites (9/10); D2 write
gates neither weakened nor duplicated (9/10); D3 read shape matches the DDL's
real `>= 0` domain, so it is not a validation regression (8.5/10); D4 read shape
never accepts input, so it is not a security boundary (8/10); D5 bounded
`amountDzd` vs permissive `purchasePriceDzd` is semantic - use vs echo (9/10);
D6 bounded computed `totalDzd` is precision-driven, not inconsistent (8.5/10);
D7 the governing rule ("a read path may only refuse to USE an unrepresentable
value, never to represent it") holds at every site (9/10); D8 charge/revision
permissiveness keeps the audit chain readable (8.5/10); D9 reasoning is
co-located with the decision (8/10). No blocker.

  parent's explicit "refuse to use" rule, and the design doc records why.
- Deferred: F3, F4 - pre-existing, outside #413; F3 is already a reported
  parent follow-up.
