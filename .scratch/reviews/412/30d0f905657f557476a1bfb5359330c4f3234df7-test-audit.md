  `100.005`, which the old float product happened to round correctly.

  wrong partition like `[29, 1]` passed.
- The draft test named "once" never re-rendered, so the `appliedDraftRef` guard
  was untested.

  crossed end-to-end; the derivation tests used a fixed March period.
- `parsePositiveInteger` and the service had no test for a day count past the
  safe-integer range.
